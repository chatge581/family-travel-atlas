# 大阪10地点试做

本轮范围：大阪市及周边，3–6岁家庭；不是全城清单，也未证明这些地点在中文攻略中稀缺。伊丹位于兵库县，明确标为大阪周边。低价与较高票价的设施都保留，以测试评分差异。全部为桌面研究候选，非实地测评。

## 已完成

- 10个结构化记录、9张候选卡；天王寺动物园官网两处返回503，暂不展示。
- 资料保存在 `data/osaka-pilot.json`；由Python生成 `output/osaka-pilot.md` 和单文件 `output/osaka-pilot.html`，无服务器、无第三方Python依赖。
- 24个官方/补充来源做了两轮实时读取：22个可读取，第二轮文本指纹未变；动物园2个失败。指纹比较不是语义核实，也不能保证发现所有关联公告。
- 6个规则测试通过：活动结束、来源变更/失败、旧资料过期、未知费用、票价变化对应评分、阻断对象不展示。
- 图片先记录官方页面线索，未下载或复用照片。Kids Plaza官网明确禁止未经许可转载图片，说明公开可读不能直接推定可转载。图片权利线索缺失时允许无图出卡，不等待用户补资料。

## 主要发现

- 自然史博物馆与长居植物园存在门票互通规则，可作为以后组合的线索，不重复累计门票，不生成未经核实的半日行程。
- Kids Plaza：标准两大一名3–5岁儿童3500日元；指定平日14点后2300日元，但管状滑梯平日只开放到14点。便宜有代价，需并列显示。
- Duskin：入馆免费、甜甜圈球装饰每套300日元；完整制作仅小学以上、需提前抽签，不推给学龄前儿童。官方FAQ给参观约1小时，不含制作。
- 杯面博物馆：入馆免费，自己做杯面每份500日元。门票经济性5星不是体验全免费。
- 扇町公园更新游具面向6–12岁，不能用旧幼儿好评覆盖新公告。
- 部分官网只写步行米数，不为凑齐星级自行换算分钟；户外遮蔽条件未确认也不硬给天气星级。

## 运行

在仓库目录：

```sh
python3 scripts/pilot.py --check
python3 -m unittest discover -s scripts -p 'test_*.py' -v
```

`--check`读取来源并生成卡片与报告；默认使用运行当天，已核查资料超过31天自动不展示。未来/历史样本可用 `--as-of YYYY-MM-DD` 测试，不将历史输出冒充当前推荐。

网页文本提取与基线位于忽略的 `.travel-cache/`。后续页面变化或失败会暂不展示依赖它的卡片；变更不会自动覆盖基线，也不自动改写JSON事实。抓取成功不更新 `checked_on`。完整页面比较可能被无关导航变更触发，当前保守下架策略尚需优化。

不要删除基线来把变更重新视为未变。重新抽取并确认受影响字段后，才应由后续流程更新事实、证据日期与基线。
